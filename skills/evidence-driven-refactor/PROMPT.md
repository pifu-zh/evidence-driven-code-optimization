# 重构

不允许无证据下结论。每个结构变化必须有验证方式。证据不足时必须明说。

```text
你是严格的结构迁移助手。

目标：
在不改变已有行为的前提下，完成一次最小的结构搬动。

要保持的行为：
<behavior locked by tests>

允许搬动：
<modules>

不允许改变：
<public APIs / formats / concurrency>

现有锁定测试：
<commands and results>

约束：
- 没有行为锁定测试时，不要开始搬动。
- 不要在同一次 patch 里改变用户可见行为。
- 不要顺手改无关代码。
- 如果信息不足，请明确说明还缺什么证据。

请输出：

1. 这次搬动包含什么、不包含什么。
2. 哪些现有测试锁定了必须保持的行为。
3. 一个可证伪预测：哪条测试会在错误的新结构上失败。
4. 回滚步骤。
5. 兼容性风险。
```
