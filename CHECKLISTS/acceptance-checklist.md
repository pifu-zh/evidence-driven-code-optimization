# 合入前检查表

## 通用

- [ ] 问题卡完整。
- [ ] 根因假设明确。
- [ ] 有至少一个可复现证据。
- [ ] patch 只包含必要修改。
- [ ] 没有混入无关格式化或重构。
- [ ] formatter 通过。
- [ ] linter 通过。
- [ ] type check 通过。
- [ ] unit tests 通过。
- [ ] integration tests 通过。
- [ ] build 通过。
- [ ] 公共 API / 数据格式变化已显式记录。
- [ ] 有回滚方式。
- [ ] 文档、runbook、迁移说明已更新。

## 功能 / 正确性

- [ ] 存在 failing test，且能证明旧代码失败。
- [ ] 新代码使该测试通过。
- [ ] 测试覆盖边界条件。
- [ ] 测试覆盖错误路径。
- [ ] 如果涉及状态机，覆盖非法迁移。
- [ ] 如果涉及并发，考虑 race detector / stress test。
- [ ] 如果涉及外部输入，考虑 fuzz / property test。
- [ ] 没有 broad catch 掩盖错误。
- [ ] 没有删除或弱化已有断言。

## 性能

- [ ] 性能目标写成数字。
- [ ] benchmark 环境固定。
- [ ] 数据集和输入规模固定。
- [ ] 并发和预热策略固定。
- [ ] 有 before benchmark。
- [ ] 有 after benchmark。
- [ ] 采样次数足够，不只看单次结果。
- [ ] 报告 P50 / P95 / P99，不只看平均值。
- [ ] 目标指标达到预算。
- [ ] 检查了 CPU、内存、IO、DB query、网络调用是否被转嫁。
- [ ] 相邻场景没有明显退化。

## AI 参与

- [ ] AI 候选假设已被记录。
- [ ] 至少一个假设被实验证实或排除。
- [ ] 没有把未验证的 AI 结论当作事实。
- [ ] 被拒绝方案也保留记录。
- [ ] 最终 patch 经过了人工 review。
- [ ] AI 没有引入无证据的大重构。

## 归档

- [ ] evidence record 已补全。
- [ ] 根因家族已更新。
- [ ] 可复用测试模板已沉淀。
- [ ] 后续动作已列出。
